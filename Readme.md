**⚙️ How to Run**
----------------

### Setup

1. Install Node.js and npm (if not already installed).
2. Clone the project repository using Git.
3. Run `npm install` to install the project dependencies.

### Environment

1. Set the environment variables in the `.env` file or using a environment variable manager.
2. Set the database connection settings in the `config/database.js` file.

### Build

1. Run `npm run build` to build the project.
2. Run `npm run start` to start the project.

### Deploy

1. Deploy the project to a production environment using a deployment tool such as Docker or Kubernetes.
